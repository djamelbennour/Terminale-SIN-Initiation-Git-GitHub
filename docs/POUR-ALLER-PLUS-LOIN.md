# 🚀 Après les 12 défis

> **Pour aller plus loin — Terminale STI2D SIN**

Vous avez acquis les bases. La suite consiste à utiliser Git comme un outil de projet.

## 1. Inspecter un commit

```bash
git show HASH
```

## 2. Comprendre fetch et pull

```bash
git fetch
git pull
```

- `fetch` récupère les informations du distant sans intégrer directement les changements ;
- `pull` récupère puis intègre les changements.

## 3. Découvrir les conflits

Lorsque deux branches modifient la même zone d'un fichier, Git peut demander une décision humaine. C'est un **conflit de fusion**.

## 4. Découvrir les Pull Requests

Une Pull Request permet de proposer l'intégration d'une branche dans une autre, relire les changements et discuter avant la fusion.

## 5. Continuer en BTS CIEL

Les notions suivantes prolongent naturellement cette initiation :
- inspection avancée de l'historique ;
- branches multiples ;
- résolution de conflits ;
- `fetch` et `pull` ;
- Pull Requests ;
- automatisation avec GitHub Actions.

> Le meilleur moyen de progresser reste de pratiquer sur de petits projets réels.
